# Video Subtitle Remover — русский интерфейс (Windows)

Неофициальная русифицированная сборка [Video Subtitle Remover](https://github.com/YaoFANGUK/video-subtitle-remover) версии **1.4.0**.

- Интерфейс: русский (по умолчанию), доступны другие языки.
- Система: Windows, вариант сборки с NVIDIA CUDA 11.8.
- Основной проект и авторы: [YaoFANGUK/video-subtitle-remover](https://github.com/YaoFANGUK/video-subtitle-remover).
- Исходный код основной программы зафиксирован на коммите `e109b9ddc1d0e8f153199dfa05c1d767546906d8`.
- Лицензия исходного проекта: Apache-2.0.

## Скачать

Откройте **Releases** справа и скачайте **все части** архива `vsr-1.4.0-ru-nvidia-cuda11.8.7z.001`, `.002`, `.003` в одну папку. Распакуйте **первую часть `.001` через 7-Zip** — остальные подтянутся автоматически.

Это *неофициальная* локализация; авторы оригинала не отвечают за эту сборку. В репозитории хранятся файлы локализации и инструкция сборки.
